# NBProf Research Hub — v1.0.0

## Première version majeure

### Fonction phare : assistant guidé de création de projet
- parcours en 4 étapes : sujet, objectif, feuille de route, validation ;
- génération locale de jalons adaptés à l’étape de recherche ;
- génération de premières tâches avec priorités et échéances ;
- rythmes de planification souple, standard ou intensif ;
- création directe dans « Mes projets » avec compatibilité tableau de bord et rapport ;
- données conservées localement sur l’appareil ;
- interface disponible en français, anglais et arabe.
